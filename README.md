## 🐟 关于我

一只在飞牛 NAS 上跑 DeepSeek Harness 的人。白天写前端，晚上把一堆服务塞进 Docker 里，
再让 AI 替我去刷 B 站、写日报、念语音。

喜欢的东西很杂但有一条主线：**让机器替我干活，并且干得好看。**

- 🔭 正在折腾：本地语音克隆（GPT-SoVITS / Edge TTS）、DSH 插件、自托管全家桶
- 🌱 在学：Agent 工具链、MCP、Rust
- 🐳 家里常驻：Clash / mihomo、Cloudflare Tunnel、一堆 Node 小服务
- 💬 闲聊关键词：NAS、自托管、TTS、B站、Vue
