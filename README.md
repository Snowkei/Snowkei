## 🐟 关于我

前端工程师。白天写界面，晚上把一堆服务塞进 Docker、挂上隧道，再让 AI 替我去刷 B 站、写日报、念语音。

在意的东西比较具体：布局要稳、动效要克制、加载要快；工具应该安静地工作，能私有就私有，能自动化就别手动。

- 🔭 正在折腾：本地语音克隆（GPT-SoVITS 零样本 + Edge TTS）、DSH 插件、自托管全家桶
- 🌱 在学：Rust、Agent 工具链、MCP
- 🐳 家里常驻：Clash / mihomo、Cloudflare Tunnel、一堆 Node 小服务
